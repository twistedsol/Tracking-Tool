# Realone | Real Universe

My personal site: cloud security tracking, labs, and how to reach me. It is a single `index.html` with no build step, in English and French, with a dark and a light theme.

## View it

Open `index.html` in a browser, or use the live version once GitHub Pages is on (the address shows under **Settings > Pages**).

## Labs

I'm building a few hands-on cloud security exercises in public over 30 days:

- **Log detector** (in progress): a Python script that reads cloud audit logs and flags root logins, brute-force attempts, public buckets and switched-off logging.
- **Misconfiguration scan** (planned): scan a test environment with an open-source tool and write up the findings.
- **Cloud audit alerts** (later): send real CloudTrail logs from a free-tier account into alerts.
