Labs

Hands-on exercises I'm building in public over 30 days. Each one gets a short write-up when it's done.

Done

Log detector

A Python script that reads cloud audit logs and flags root logins, brute-force attempts, public buckets, and switched-off logging.

Done

Misconfiguration scan

Scanned deliberately vulnerable Terraform with Checkov, then fixed three findings on one S3 bucket. Passed checks went from 25 to 32.

Done

IAM policy checker

Reads AWS IAM policy files and flags risky permissions with seven rules. Standard library only, 32 tests, no cloud account needed.

Done

Secrets scanner

A Python tool that finds passwords, cloud keys and tokens left in code, and never prints the full secret. Standard library only, 43 tests, no cloud account needed.

Done

Security headers checker

A Python tool that reads the security headers of a web page and flags missing or weak ones. Standard library only, 47 tests, and it works on saved header files with no internet needed.

Done

Password policy checker

A Python tool that reads a password policy file and flags weak settings like short minimums, no lockout, no MFA and weak hashing. Standard library only, 34 tests, no real passwords involved.

Done

SSH config checker

A Python tool that reads an SSH server config file and flags risky settings like root login, password logins and weak ciphers. It only reads files and never connects to a server. Standard library only, 41 tests.

Done

Dockerfile checker

A Python tool that reads Dockerfiles and flags risky habits like running as root, secrets written in the file and piping a download into a shell. Each finding shows its line number. It only reads files and never builds anything. Standard library only, 46 tests.

Done

Workflow checker

A Python tool that reads GitHub Actions workflow files and flags risky settings like loose permissions, unpinned actions and text from issues pasted into commands. Each finding shows its line number, and it checks its own workflow too. Standard library only, 51 tests.

Done

Docker Compose checker

Reads docker-compose files and flags risky settings such as privileged containers, the Docker socket, public database ports and hardcoded secrets, with line numbers. 76 tests.

Done

Kubernetes manifest checker

Reads Kubernetes files and flags risky settings such as privileged containers, host mounts, running as root, missing limits and hardcoded secrets, with line numbers. 61 tests.

Later

Cloud audit alerts

Send real CloudTrail logs from a free-tier account into alerts for risky actions like root logins.
